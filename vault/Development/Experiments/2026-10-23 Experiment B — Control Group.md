# Experiment B — Control Group

## Question

Is the observed post-lesson loss reduction attributable to the lesson content (the 5 phonics exemplars), or could it result from any optimization steps on any text — or even from evaluation-time artifacts like the model simply being in a different state after N forward passes?

## Hypothesis

1. **Control 1 (no-update baseline):** A model that receives no gradient updates will show negligible loss change between pre- and post-evaluation (delta $\approx 0$), confirming that the loss reduction in Lesson 1.1 was not an artifact of repeated evaluation.
2. **Control 2 (random text corpus):** A model trained for the same number of steps on an unrelated control corpus (e.g. random byte sequences or unrelated English text) will show significantly less loss reduction on the phonics test items than the model trained on actual Lesson 1.1 exemplars.
3. **If Control 2 shows comparable loss reduction**, this would suggest the model is simply learning generic byte-level statistics (e.g. "English letters appear more than control characters"), not lesson-specific phonics patterns.

## Variables and Conditions

- **Independent variable:** Training corpus content:
  - **Treatment group:** The original 5 Lesson 1.1 exemplars.
  - **Control group 1:** No training (zero gradient steps).
  - **Control group 2:** 15 iterations on a control corpus of equivalent token length.
- **Control corpus options (pick one or both):**
  - *Option A — Random bytes:* Randomly generated byte sequences matching the length distribution of the 5 exemplars. Tests whether any structured optimization reduces loss.
  - *Option B — Unrelated English:* Sentences with no phonics/CVC overlap, e.g. `"The system processes data files."`, `"Network latency affects throughput."`. Tests whether generic English text training transfers to phonics evaluation.
- **Measured outcomes:**
  - Pre/post evaluation loss on the original 4 test items (same as Lesson 1.1 experiment).
  - Loss delta for each condition.
  - Generated text quality comparison across conditions.
- **Controls:**
  - Same model architecture (BabyLM 25M).
  - Same optimizer config (AdamW, $\eta=10^{-3}$, grad clip = 1.0).
  - Same number of iterations (15).
  - Same evaluation items.
  - Fixed random seed across all conditions (seed=42).
- **Test items (same as Lesson 1.1):**
  1. Prompt: `"The cat sat on the "` -> Target: `"mat."`
  2. Prompt: `"The sun is "` -> Target: `"hot."`
  3. Prompt: `"The dog can "` -> Target: `"run."`
  4. Prompt: `"The red pen is on the "` -> Target: `"bed."`
- **Environment / architecture:** Debian Linux x86_64, Python 3.13.5, PyTorch 2.14.1 (CPU development mode).
- **Code reference:** `harness.school.classroom.ClassroomSession`, `harness.learner.model.BabyLM`.

## Procedure

1. Instantiate `BabyLM` with random weights (seed=42) — this is the treatment model.
2. **Treatment condition:** Run the standard Lesson 1.1 learning cycle (15 iterations on 5 phonics exemplars). Record pre/post loss on the 4 test items.
3. Instantiate a fresh `BabyLM` with the same seed (seed=42) — this is Control 1.
4. **Control 1 (no-update):** Evaluate pre-loss on the 4 test items. Do NOT train. Re-evaluate post-loss (should be identical or near-identical). Record the delta.
5. Instantiate a fresh `BabyLM` with the same seed (seed=42) — this is Control 2.
6. **Control 2 (random/unrelated corpus):** Run 15 training iterations on the control corpus. Evaluate pre/post loss on the same 4 test items. Record the delta.
7. Compare loss deltas across all three conditions.
8. Log results.

### Code Changes Required

- **No new harness methods strictly required** — the existing `ClassroomSession.evaluate_test_items` and `BabyLM.train_step` can be used directly.
- **Suggested approach:** Write a standalone experiment script (e.g. `experiments/run_experiment_b.py`) that:
  1. Creates three model instances with the same seed.
  2. Runs the treatment via existing `run_learning_cycle` or direct training loop.
  3. Runs Control 1 by calling `evaluate_test_items` twice with no training in between.
  4. Runs Control 2 by training on the control corpus using `train_step` directly, then evaluating.
  5. Outputs a comparison table.
- **Consider adding a helper:** `ClassroomSession.run_control_comparison(exemplars, control_corpus, test_items, iterations)` that automates all three conditions in one call and returns a structured comparison dict.

## Interpretation

### 1. Control 1 confirms loss reduction is not an evaluation artifact

The no-update condition produced **exactly zero delta** (+0.0000) across all items, with identical pre/post losses to 4 decimal places. This definitively rules out any evaluation-time artifacts — the loss reduction in the treatment condition is caused by the gradient updates, not by repeated forward passes or state changes during evaluation.

### 2. Random bytes actively harm phonics evaluation performance

Control 2a (random bytes) produced a **negative delta** (−0.69 avg), meaning the model got *worse* at predicting phonics targets after training on random byte sequences. This makes sense: training on random bytes shifts the model's byte-level distribution away from English patterns, increasing cross-entropy on English text. Two items even showed substantial degradation (Item 2: −0.78, Item 4: −1.86). This is strong evidence that the treatment's loss reduction is **not** a generic effect of "any optimization on any data" — the wrong data makes performance worse.

### 3. Unrelated English transfers partially but not fully

Control 2b (unrelated English) showed a meaningful delta of **+3.28** — about **70%** of the treatment's +4.71. This reveals that a significant portion of the loss reduction comes from learning generic English byte-level statistics (letter frequencies, common bigrams, whitespace patterns) rather than lesson-specific phonics content. However, the treatment still outperformed by **+1.43 points**, and the gap was largest on Item 4 (+4.88 vs +1.32), which has the longest prompt and most specific target — suggesting the lesson-specific advantage grows with task specificity.

### 4. Training loss convergence differs by corpus

All three training conditions reduced their own training loss, but the treatment (phonics) converged furthest (0.69 final loss) vs. unrelated English (1.65) vs. random bytes (2.74). This reflects how well each corpus fits the model's capacity — short, repetitive phonics sentences are easier to memorize than diverse technical English or random bytes.

### 5. Generation quality separates the conditions

The treatment produces English-shaped output (`t..e`, `r t t.`, `t.he.`) — correct letters, spaces, and periods. Control 2b produces English-shaped but non-phonics output (`rorfng`, `fircti`, `tnrts`). Control 2a produces non-English output (`kMw`, `kCZqki`, `qBrP+N`). The treatment's advantage is not just lower loss but qualitatively better phonics-aligned generation.

## Limitations

- A single seed limits statistical confidence; pair with [[2026-10-23 Experiment C — Multiple Random Seeds|Experiment C]] for multi-seed validation.
- The control corpus choice matters — random bytes vs. unrelated English test different things. Both were run, providing complementary evidence.
- The unrelated English corpus is still English text with ASCII letters, spaces, and periods — it shares byte-level distributional properties with the phonics exemplars. A more distant control (e.g. tokenized Chinese, base64 data) might show even less transfer.
- This experiment controls for the training step effect but does not control for evaluation artifacts (e.g. dropout state, batch norm) — though BabyLM uses dropout=0.0 by default, minimizing this concern.

## Conclusion

- **Supported:**
  1. The loss reduction is caused by gradient updates, not evaluation artifacts — Control 1 showed exactly zero delta. (Hypothesis 1 confirmed.)
  2. The lesson content matters — Control 2a (random bytes) made performance *worse* (−0.69), proving that not just any optimization improves phonics loss. (Hypothesis 2 confirmed.)
  3. The treatment outperforms unrelated English by +1.43 points, confirming that lesson-specific phonics content contributes beyond generic English byte statistics. (Hypothesis 3 partially confirmed.)
- **Not established:**
  1. Whether the +3.28 delta from unrelated English represents "generic English statistics" or structural overlap (shared words like `the`, `is`, `can`) — the control English sentences were designed to avoid CVC words but share sight words.
  2. Whether the treatment-vs-control gap (+1.43) holds across multiple seeds.
