# 2026-10-24 Lesson 1.1 Proper Testing

## Question
Does Lesson 1.1 as written in the curriculum actually teach the model to complete alphabet sequences?

## Method
Tested with full sequences from Lesson 1.1: `["a b c d e f g", "c d e f g h i", "m n o p q r s", "t u v w x y z", "e f g h i j k"]` plus prefixes. Used 4 seeds, 15-20 iterations, tracked both loss and greedy generation accuracy on held-out items from Assessment 1.

## Results

With full sequences only (4 seeds):
| Seed | Δ Held-out Loss | Greedy Acc (Held-out) |
| :-- | :--------------- | :-------------------- |
| 42  | +5.0337         | 0.00%                 |
| 123 | +4.6939         | 0.00%                 |
| 7   | +4.2920         | 0.00%                 |
| 999 | +3.4214         | 0.00%                 |
| AVG | +4.3602         | 0.00%                 |

## Findings

1. **Loss improves a lot** but generation accuracy is 0% with greedy decoding
2. **Model learns the pattern but not stably enough to generate correctly** - from rank tracking, it reaches rank 1 sometimes but not consistently
3. **The curriculum's approach of using full sequences teaches the pattern, but current training setup doesn't make it stable**
4. **High variance across seeds** confirms instability

## Implications

- The lesson as written CAN teach the capability, but it's fragile
- The pass criteria in the curriculum say "Post-training loss delta > +2.0 on held-out items" - by this metric, all seeds pass
- But the actual ability to generate correct completions is not there
- This is a critical distinction - we need to decide what "pass" means

## Recommendation
Before implementing all modules, we need to either:
1. Adjust training (more iterations, different learning rate) to make learning more stable
2. Adjust the lesson format to be more explicit
3. Adjust evaluation to better match what was taught
4. Or change pass criteria to require generation accuracy

But as advised, don't change the curriculum yet - understand the issue first. The harness test showed loss-based pass/fail works; generation is separate. Maybe both metrics matter?
