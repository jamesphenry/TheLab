# Development Documentation

This folder contains internal engineering and architecture documentation for building and maintaining the **AI Learner Laboratory (AI School)** harness and environment.

> [!NOTE]
> This folder is strictly for human developers and harness maintainers. Agentic roles (Learner, Teacher, Assessment) have no read or write access here.

## Core Documents

- [[Project Overview|Harness Project Overview]] — Mission, goals, constraints, and scope.
- [[Architecture|System Architecture]] — Component model, data flow, safety invariants, and subsystem responsibilities.
- [[Roadmap|Development Roadmap]] — Current milestone, active tasks, and upcoming phases.
- [[Build and Test|Build, Run & Test Guide]] — Environment setup, canonical commands, and verification procedures.
- [[00-System/Experiment Workflow|Experiment Workflow Guide]] — Plan-to-analysis checklist and current execution boundaries.
- [[00-System/Server Experiment Access|Server Experiment Access]] — Read-only SSH identity and repository preflight.

## Subdirectories

- **[[Decisions/Decision Index|Architecture Decisions (ADRs)]]:** Formal records of structural and architectural choices (`ADR-0001`, etc.).
- **[[Experiments/Experiments Index|Experiments Index]]:** Dated research and harness experiment records, including model comparisons, controls, and diagnostic studies.
- **[[Debugging/Debugging Index|Debugging Notes]]:** Post-mortems, root-cause analyses, and solutions to thorny issues.
- **[[Logs/Logs Index|Session Logs]]:** Dated development journal notes detailing work accomplished per session.
