# Lesson 3.1 — Subject-Verb Completion

## Objective
Teach the model to fill in verb blanks in simple Subject-Verb patterns.

## Teaching Material & Exemplars
1. **Common animal actions:**
   - `The dog can ` -> `run.`
   - `The cat can ` -> `jump.`
   - `The bird can ` -> `fly.`
   - `The fish can ` -> `swim.`
   - `The frog can ` -> `hop.`

2. **With different subjects:**
   - `A boy can ` -> `run.`
   - `A girl can ` -> `sing.`
   - `The pig can ` -> `eat.`
   - `The ant can ` -> `walk.`
   - `The bee can ` -> `fly.`

3. **Mixed actions:**
   - `The rat can ` -> `run.`
   - `The bug can ` -> `crawl.`
   - `The kid can ` -> `play.`
   - `The pup can ` -> `bark.`
   - `The hen can ` -> `peck.`

## Practice Exercises
- Complete: `The fox can ` -> `run.`
- Complete: `A duck can ` -> `swim.`
- Complete: `The bat can ` -> `fly.`

## Notes
Keep verbs short (3-4 letters). Use the consistent pattern `can ` as the template. This teaches SVO-like structure through pattern completion. Focus on actions that are easily associated with the subject.
