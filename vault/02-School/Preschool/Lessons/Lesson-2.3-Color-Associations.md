# Lesson 2.3 — Color Associations

## Objective
Teach the model to associate objects with their common colors through pattern completion.

## Teaching Material & Exemplars
1. **Basic color-object pairs:**
   - `The apple is ` -> `red.`
   - `The banana is ` -> `yellow.`
   - `The grass is ` -> `green.`
   - `The sky is ` -> `blue.`
   - `The snow is ` -> `white.`

2. **More associations:**
   - `The carrot is ` -> `orange.`
   - `The grape is ` -> `purple.`
   - `The coal is ` -> `black.`
   - `The milk is ` -> `white.`
   - `The sun is ` -> `yellow.`

3. **Varied sentence forms:**
   - `An apple is ` -> `red.`
   - `The leaf is ` -> `green.`
   - `A rose is ` -> `red.`
   - `The orange is ` -> `orange.`
   - `The lime is ` -> `green.`

## Practice Exercises
- Complete: `The cherry is ` -> `red.`
- Complete: `The lemon is ` -> `yellow.`
- Complete: `The blueberry is ` -> `blue.`

## Notes
This lesson introduces more varied vocabulary. Keep color names short and common. The pattern is consistent (`is ` followed by color). Avoid abstract color concepts - stick to concrete objects with strong color associations.
