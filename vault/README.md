# AI Learner Laboratory — Obsidian Vault

This vault functions as the persistent environment, curriculum repository, and experiment notebook for the **AI Learner Laboratory**.

## Directory Structure
- `00-System/`: Technical harness rules, folder access policies, and scheduling routines.
- `01-Learner/`: Learner-owned files (goals, self-assessment, pending questions).
- `02-School/`: School subjects (`Programming/`, `Mathematics/`, etc.) with lessons, assignments, and exams.
- `03-Experiences/`: Chronological records of lessons and discussions.
- `04-Memory/`: Retrievable notes and synthesized principles maintained by the learner.
- `05-Dreams/`: Idle-time reflection logs and generated hypotheses.
- `06-Labs/`: Practical coding and reasoning lab environments.
- `07-Reports/`: Rubrics, grade reports, and measurable evaluations.
- `Development/`: Engineering documentation, architecture, roadmap, ADRs, debugging, and session logs.
- `Templates/`: Standard templates for notes, experiments, and decisions.
