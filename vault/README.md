# AI Learner Laboratory — Obsidian Vault

This vault functions as the persistent environment, curriculum repository, and experiment notebook for the **AI Learner Laboratory**. Start at [[Home]]. Follow [[00-System/Vault Architecture|Vault Architecture]], [[00-System/Documentation Standard|Documentation Standard]], and [[00-System/Vault Maintenance|Vault Maintenance]] for note roles and research-record conventions.

## Directory Structure
- `00-System/`: Technical harness rules, folder access policies, and scheduling routines.
- `01-Learner/`: Learner-owned files (goals, self-assessment, pending questions).
- `02-School/`: School subjects (`Programming/`, `Mathematics/`, etc.) with lessons, assignments, and exams.
- `03-Experiences/`: Chronological records of lessons and discussions.
- `04-Memory/`: Retrievable notes and synthesized principles maintained by the learner.
- `05-Dreams/`: Idle-time reflection logs and generated hypotheses.
- `06-Labs/`: Practical coding and reasoning lab environments.
- `07-Reports/`: Assessment reports and cross-record research audits; see [[07-Reports/Reports Index|Reports Index]].
- `Development/`: Engineering documentation, architecture, roadmap, ADRs, debugging, logs, and experiment records; see [[Development/Experiments/Experiments Index|Experiments Index]].
- `00-System/`: Policies and the vault's documentation and maintenance guides.
- `Templates/`: Reusable templates; see [[Templates/README|Templates Overview]].

See [[Home]], [[NOTES]], and [[future|Future Research Directions]] to begin.
