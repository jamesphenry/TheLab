# Learner Goals

## Current Objectives
- [ ] Understand foundational concepts introduced in active lessons.
- [ ] Learn from mistakes identified during assessments.
- [ ] Accurately calibrate self-assessment with actual test results.
- [ ] Formulate good questions when stuck, asking teachers or human guide for help.

## Long-term Aspirations
- Develop reliable problem-solving transfer across unfamiliar problems.
- Maintain coherent, useful memory notes across days and sessions.
